# Graphics G7C - Tone mapping, exposure and color balance

The existing renderer outputs directly to the default framebuffer, with no explicit gamma correction or framebuffer-sRGB conversion. Its material/sky palettes are effectively display-referred, even though their legacy lighting and alpha blending use ordinary arithmetic. Treating these values as scene-linear HDR and adding ACES or another gamma encoding directly would damage the approved G7B image.

`ColorGrading` therefore captures the complete, unchanged scene in a reusable **RGBA16F + depth24** framebuffer. Floating-point color retains over-range shader highlights before the default framebuffer could clip them. One fullscreen triangle decodes the composed display-referred signal with the sRGB transfer function, applies linear-luminance exposure/contrast/highlight compression and saturation, then encodes it once. Framebuffer-sRGB conversion is disabled during this operation and its prior state restored. Sky, opaque architecture, water and composited glass all receive the same final operation. This is an HDR-capable working buffer, not a conversion of the existing materials/lighting/blending into a physically linear HDR renderer.

Central settings in `ColorGrading.h`: **+0.08 EV**, **1.025 contrast** around 0.18 linear luminance, **0.985 saturation**, and a smooth rational highlight shoulder above **0.65 linear luminance**, asymptotically approaching white. Neutral white balance preserves G7B's sunlight and glass colors. Luminance scaling preserves hue; only out-of-gamut highlights compress toward equal-luminance white rather than clipping individual channels. Static sub-byte output dither limits banding. Shadows are not thresholded or crushed to black. The effect is deliberately mild rather than a strong filmic filter.

**F7** (previously unused) toggles the stage; press/hold/focus handling matches F6. OFF renders directly through the original G7B path and skips the scene FBO/composite. The title displays the color state alongside FPS, movement mode and F6. F6 remains independent; neither F7 state invalidates the cached shadow map. Resources allocate on the first enabled frame and resize only when framebuffer dimensions change; minimized windows skip rendering. At 1280x720, attachments use approximately **10.55 MiB**. Enabled cost: **one draw / one fullscreen triangle**, no additional scene geometry, shadows, textures per object or material variants.

Debug x64 build and full-scene shader/link/OpenGL checks passed. Matched OFF/ON views were inspected for Baiterek, Northern Lights, Nur Alem/EXPO, residential sunny/shaded facades, Astana Arena and an elevated city overview. The result retains blue sky and blue-green glazing, gently lifts midtones and rolls off bright architecture/reflections. Five matching F7-OFF captures are byte-identical to the saved G7B images. Clipped-channel pixels decreased from 65 to 30 in the Baiterek frame and 8 to 0 in the Northern Lights frame. FBO completeness, reuse across 640/960/1280 widths, zero-sized-frame bypass, framebuffer/viewport/depth/blend/offset/texture restoration, F6/F7 input handling and stationary shadow reuse passed.

One brief alternating warmed comparison, Intel UHD / Debug 1280x720, same overview and F6 ON: **OFF 64.91 FPS / 15.405 ms; ON 64.33 FPS / 15.544 ms** (approximately **+0.14 ms / 0.9%**). This short, same-run sample does not guarantee a visible-window FPS or isolate GPU time. No extended profiling was performed.
