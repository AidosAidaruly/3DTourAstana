# Graphics G9A - Shared optimized 3D trees

Upgraded **570 existing trees** through one shared instanced pool: Botanical Garden groves, lakeside and perimeter trees; all 157 Esil embankment trees; shared `Tree` objects around Baiterek/Ak Orda, Abu Dhabi and Khan Shatyr; and background-residential courtyard trees. Original placement loops, obstacle checks and planting coordinates remain unchanged. Old visible tree emission/submission is replaced, rather than drawing new trees over the old ones.

Five reusable variants: rounded broadleaf, columnar broadleaf, spreading broadleaf, dark layered conifer and lighter asymmetric conifer. Deciduous near models have tapered trunks, six branch forks and twelve irregular foliage clusters. Conifers use six scalloped foliage tiers and restrained branch structure. Foliage has deterministic cluster/vertex green variation; no individual leaves, textures, transparency, wind or per-frame generation. Root-derived yaw and small scale/tint variation are stable. Width is 94-100% and height 97-100% of the retained conservative envelopes; mesh validation checks normalized radial/height bounds, finite normals and outward winding. No paths or terrain were moved.

Three shared indexed LODs per variant: broadleaf **920 / 272 / 80 triangles**, conifer **512 / 204 / 110**. Combined shared meshes total **3,784 / 1,224 / 460 triangles** across five variants, plus one static instance buffer; total **292,944 bytes (~0.28 MiB)**. 160 m cells provide cached frustum rejection and hysteretic LOD selection: initialization 80/220 m, near departure/return 95/65 m, far departure/return 240/200 m. Instances batch by cell, variant and LOD, with no per-tree draw or moving-view buffer uploads. The garden overview submitted 318 visible trees in **33 draws / 186,320 triangles**; the pedestrian garden view submitted 34 draws / 250,704 triangles. These replace previous baked crowns and individual multi-draw `Tree` submissions, not additive duplicate scenery.

Tree shading reuses G7B daylight, G7A haze, G6 shadow receiving and the unchanged final composite. Garden/shared-tree shadow envelopes remain the existing inexpensive proxies. Background trees replace their former baked shadow geometry with a trunk and two coarse lobes; Esil trees now use those same coarse proxies. Detailed tree meshes are never added to the depth pass. One 2048-square shadow map, filtering, culling, cache and F6 remain intact. Proxy-builder totals are 75,776 triangles globally, including all existing landmarks; only local light-frustum ranges render on map refresh.

Debug x64, mesh/envelope/shader/OpenGL, framebuffer/texture/depth-state, all F6/F7/F8 combinations and stationary shadow reuse passed. Matched garden pedestrian/overview, central tree/residential-facing, Esil and river-overview views were inspected, with an additional background-residential courtyard check. Brief warmed Debug 1280x720 garden-overview comparison on Intel UHD, all effects ON: **61.5 -> 68.0 FPS** (16.25 -> 14.70 ms). No regression was observed; this short sample is not a guaranteed speedup or visible-window FPS.

Changed: `TreeModels.cpp/.h` (new), `Tree.cpp/.h`, `BotanicalGarden.cpp/.h`, `EsilEmbankment.cpp/.h`, `BackgroundResidential.cpp/.h`, `AbuDhabiLandscaping.cpp/.h`, `KhanDistrictLandscaping.cpp/.h`, `Scene.cpp/.h`, project/filter references and this document. G7/G8 shader code, city placement, roads, landmarks and controls remain unchanged.

Remaining: specialized vegetation baked into MEGA/EXPO, Astana Arena, Northern Lights, premium residential courtyards and greenhouse interiors; shrubs/flowerbeds are unchanged. Opaque clustered foliage is still an optimized stylized approximation, not leaf-textured botanical modeling. Stopped for F5 review. No commit or push.
